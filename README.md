# 简明提词器

一个可离线使用的浏览器提词器。支持草稿自动保存、文案库、字号调节、镜像、强制横屏和键盘切换文案。

## 文案格式

可以直接粘贴带编号的文案，标题会进入文案库，正文会进入提词画面：

```md
### 004｜半天不用全耗在路上

这里是口播正文。
```

连续粘贴多篇 `004｜标题` 格式的内容时会自动拆分。也兼容 `# 标题` 加 `---` 分隔的原格式，以及 `.md`、`.markdown`、`.txt` 文件导入。

## 本地运行

```bash
npm install
npm run dev
```

## 检查

```bash
npm run build
```
